# Dependency contract v1

Analyze has no predecessor. Plan requires an explicit complete analyze v1 report,
valid_bug, concrete evidence re-read against current source, grounded cause,
medium/high confidence, same issue/repository and no material gaps.
Unknown revision permits only a read-only proposal with fresh evidence.
Future fix/test/review/pr require a reviewed plan, authorized scope, validation,
and publication permission respectively. No automatic transitions exist.
